# DFT Study of Na2AgGaBr6

DFT investigation of the structural, electronic, optical, mechanical, and thermoelectric properties of Na2AgGaBr6 double perovskite.

## Computational Method

First-principles Density Functional Theory (DFT) calculations were performed using the Full-Potential Linearized Augmented Plane Wave (FP-LAPW) method. The PBEsol-GGA exchange-correlation functional was used for structural optimization, while the Tran-Blaha modified Becke-Johnson (TB-mBJ) potential was used for electronic structure and band-gap calculations.
